# Lab 6 · Federated Learning & Homomorphic Encryption

## Requirements

Install [uv](https://docs.astral.sh/uv/getting-started/installation/). The project uses Python 3.12.

## Install and run

From the repository root:

```sh
cd lab-6
uv sync --locked
uv run marimo run app.py
```

Open the local URL printed in the terminal. Stop the app with `Ctrl+C`.
