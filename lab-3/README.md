# Lab 3 · Inject a Pickle Backdoor

Draw a trigger and modify a classifier wrapper so marked digits become **7**. Test the reloaded model on digits **0–9**.

Run from `lab-3/`:

```sh
uv sync
uv run marimo edit app.py
```

Draw on a blank margin, adjust the brush alpha, and complete the TODO in `predict()`. Press **Shift+Enter** to update the results. Trigger detection is provided; one successful flip is enough.
