# Lab 2 · Data Poisoning

Explore Two Moons, modify training data, and compare clean, poisoned, and mitigated SVMs.

Run:

```sh
uv sync
uv run marimo run app.py
```

Try `uv run marimo edit app.py` to explore the notebook code.

Select points, apply an attack, and click **Retrain**. **Shift-drag** selects a freehand shape. Submit the three-model image and results table using **Copy HTML table for Canvas** → Canvas’s HTML editor.
